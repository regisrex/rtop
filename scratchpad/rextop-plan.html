view 02 / processes

htop's table, with a filter box and a confirm step

Sort columns toggle direction on a second press. Typing after / filters by name or full command line live, no Enter required. x never kills immediately — it opens the same confirm pattern Docker's stop action uses, so a stray keypress can't take down the wrong thing.

view 03 / docker

Container stats pulled straight from the Engine API

No shelling out to docker stats — bollard talks to the daemon socket directly, and every running container's stats are fetched concurrently so a ten-container host redraws as fast as a one-container host. a toggles running-only vs. everything, including exited containers.

architecture

Two collectors, one shared state, one render loop

Metrics are never fetched on the UI thread. Both collectors write into an Arc<RwLock<_>> on their own schedule; the render loop takes a read lock four times a second and the input loop takes a write lock only when a key actually needs one.

  DOCK["DockerMonitor::refresh\n(bollard — list + concurrent per-container stats)"]

  STATE2[("Arc<RwLock<DockerMonitor>>")]
